Fundthesis Dashboard Redesign

A comprehensive UI specification for transforming the Market Chronicle dashboard into a modern, professional-grade financial interface with improved information hierarchy, visual polish, and user experience.

Design Direction

Moving from the current light-themed newspaper aesthetic to a dark, professional trading terminal aesthetic. This direction is better suited for financial applications because it reduces eye strain during extended use, makes numerical data and color-coded changes more readable, and aligns with industry standards (Bloomberg, TradingView, etc.).

JetBrains Mono

Monospace font for all numerical data, stock symbols, prices, and percentages. Ensures consistent character width for easy scanning.

Layout Architecture

The new layout uses a three-column design with a fixed navigation header and scrolling ticker. This maximizes information density while maintaining clear visual hierarchy.

Implementation Guidelines

Spacing System

Use a 4px base unit. Common values: 8px (small gaps), 16px (component padding), 24px (section spacing), 32px (major sections). This creates visual rhythm and consistency.

Border Radius

Cards and containers: 12px. Buttons and inputs: 8px. Tags and badges: 4px. Mini elements: 4px. Keep consistent across all components.

Transitions

Use 200ms duration for hover states. Apply ease-out easing for natural feel. Properties: background-color, border-color, transform, opacity.

Responsive Breakpoints

1280px+ : Full 3-column layout. 1024px: Collapse right sidebar. 768px: Single column, stacked sections. 480px: Mobile-optimized cards.

Data Formatting

Prices: Always 2 decimal places. Percentages: 2 decimals with sign (+/-). Large numbers: Use K/M/B suffixes. Dates: Relative ("2h ago") for recent.

Accessibility

Maintain 4.5:1 contrast ratio for text. Add focus states to all interactive elements. Use semantic HTML. Support keyboard navigation throughout.

CSS Variables for Theming

All colors should use CSS custom properties to enable easy theming. If you want to support a light mode toggle, you can swap the variable values on :root or a [data-theme="light"] selector.

Recommended New Components

Sparkline Charts

Add mini inline charts (60x24px) next to watchlist items showing 24-hour price movement. Use SVG paths with the accent colors. Provides quick visual trend without cluttering the UI.

Quick Actions Bar

Floating action button cluster in bottom-right corner. Actions: Quick trade, Set alert, Add to watchlist, Share analysis. Use a FAB pattern with expandable menu.

Portfolio Donut Chart

Add a sector allocation visualization in the portfolio summary area. Interactive segments showing holdings by category. Hover reveals exact percentage and value.

Command Palette

Keyboard-triggered search (⌘K) for power users. Search stocks, navigate pages, execute actions. Shows recent searches and suggestions.
